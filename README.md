# Customer Retention & Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes customer sales and retention data to help answer a business question:

> **Customer retention has fallen — when, where, and why is this happening?**

The project combines **Excel dashboarding** and **MySQL analysis** to identify sales trends, customer retention patterns, regional performance, and high-value customers.

## 🎯 Objectives

- Analyze overall sales and revenue performance
- Track monthly revenue trends
- Compare revenue across regions and product categories
- Measure customer retention
- Identify regions with stronger or weaker retention
- Identify high-value customers
- Perform SQL-based business analysis

## 🛠️ Tools Used

- **Microsoft Excel** — data analysis, PivotTables, PivotCharts and dashboard
- **MySQL** — SQL-based data analysis
- **GitHub** — project documentation and version control

## 📊 Dashboard

The Excel dashboard includes:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Customer Retention %
- Revenue by Region
- Revenue by Category
- Monthly Revenue Trend
- Customer Retention by Region
- Customer Retention Overview

## 🔎 Key Analysis

The SQL analysis covers:

- Aggregations using `SUM()`, `COUNT()` and `AVG()`
- `GROUP BY` and `HAVING`
- Sorting and filtering
- Customer-level analysis
- Common Table Expressions (CTEs)
- Window functions such as `RANK()` and `LAG()`
- Monthly revenue growth analysis
- High-value customer identification
